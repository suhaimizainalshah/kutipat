Sitemap: collect from many pages

Like Web Scraper

Start pages, then selectors in a tree: an element makes one row per match; text, link, image, attribute, HTML and table fill its columns; a link set to follow opens each page it points to, where its own child selectors run; pagination visits the next pages.

Sitemaps from the Web Scraper extension can be imported, and exported ones open there too.

Save the page’s resources

Images, media, styles, scripts, fonts

Finds the files this page loaded and saves them in one ZIP, sorted into folders, with a list of where each came from. Data requests the page made are left out.

Check that you may reuse what you download: images, fonts and media usually belong to their creators.

Address bar: type kutip and press Enter to open Kutipat on the page you’re on.

No analytics, no tracking: Kutipat never records which sites you visit. Only scrape data you’re allowed to use, and follow each site’s terms.
